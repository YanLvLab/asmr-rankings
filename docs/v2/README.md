# 静响榜 V2 改版记录

## 项目审计

- 原版首屏由大型宣传区与精选封面占据；在 1440×900 窗口中，看不到资源列表。
- 原版移动端存在横向内容溢出，按钮和卡片被截断。
- 主要功能挤在单个 `App.tsx`，样式文件有多轮覆盖，发现与榜单页面没有清晰的一级导航。
- 数据已包含双平台 634 支视频、290 位创作者，以及 B站算法分数和历史快照。采集、清洗、测试、每日 Action 和 Pages 流程可继续使用。

V2 删除大型 Hero、动态声波、滚动入场、进度条及冗余卡片信息。新增四个一级入口、紧凑的首屏筛选与内容、本地收藏工具、随机发现、移动端底部导航。原有数据管道和榜单权重没有更改。

## 验收结果

- `npm test`：14 项通过。
- `npm run build`：TypeScript 类型检查与 Vite 生产构建通过。
- 本项目未提供 `npm run lint`。
- Chrome/Playwright Core 使用仓库真实 JSON 验证：360、390、430、768、1024、1440、1920px 均无横向溢出；移动底部导航完整可见。
- 生产预览验证：筛选写入 URL、随机发现遵守平台筛选、列表模式、视频/创作者收藏持久化、备份导出导入、真实外链、最近访问、移动筛选抽屉与数据请求失败后的重试均通过。
- 数据检查：视频 ID 与创作者 ID 无重复；当前数据没有少于 180 秒、缺失标题/创作者/封面、非法平台域名的条目。

## 限制

- YouTube 现有数据没有逐条收录时间，不能提供准确的“最新收录”混合排序。页面保留“最新发布”和“最近有快照”两个明确口径。
- 数据采集由外部平台可用性决定；网络失败、地区或登录限制不等于视频下架。
- 自动清洗无法保证每条视频都符合每个人对助眠内容的偏好；可继续完善规则与人工抽查。
- 本分支仅供评审，尚未合并至 main，也未替换线上稳定版。
