# 静响榜 · HUSH INDEX

[打开线上稳定版](https://yanlvlab.github.io/asmr-rankings/) · [GitHub 仓库](https://github.com/YanLvLab/asmr-rankings)

静响榜是 YouTube 与哔哩哔哩 ASMR 内容的静态索引站。搜索、筛选、收藏作品，然后直接前往原平台观看。本站没有账号、站内播放器或后端服务。

## 页面与语言

- **发现**：搜索标题与创作者；按平台、声音类型、时长、发布时间、已标注的女性创作者筛选；切换网格/列表；从当前结果随机发现。
- **榜单**：保留 B站今日热榜、本周上升、长尾常听的原算法，另按真实播放量提供双平台各自的热门作品。
- **创作者**：按名称、平台、类型筛选，展示公开粉丝/订阅数、已收录作品数、代表作品及原平台主页。
- **收藏**：本机保存视频与创作者、最近主动打开的视频；支持关闭或清空访问记录，以及 JSON 导入导出。

筛选状态写入页面 URL，复制地址即可分享。收藏、访问记录、显示模式和筛选偏好保存在版本化 LocalStorage 中；浏览器不允许存储时，页面仍能临时使用。清除浏览器数据可能使收藏丢失，跨设备使用请导出备份。

导航栏的 **EN / 中文** 按钮切换全站界面语言，选择也保存在本地。导航、筛选、榜单口径、卡片操作、收藏工具、空状态、错误提示和隐私页均提供中英文本。视频标题与创作者名称保留原平台写法；本站不生成未经核实的译名。

## 本地开发

```powershell
npm ci
npm run dev
npm test
npm run build
```

构建产物位于 `dist/`。Vite 使用相对资源路径，页面路由使用 URL hash，可直接部署到 GitHub Pages。项目没有 `npm run lint` 命令；`npm run build` 同时执行 TypeScript 类型检查。

## 数据与自动更新

前端只读取 `public/data/rankings.json`。日常更新由 `.github/workflows/refresh-and-deploy.yml` 在 **main** 分支执行：分别采集双平台公开数据，重新清洗，运行测试，写回快照并构建/发布。采集失败时保留已有数据并标记来源状态。功能分支不会触发线上部署。

手动运行：

```powershell
npm run collect
npm run collect:youtube
npm run sanitize
npm test
npm run build
```

采集脚本不使用 YouTube API Key，不破解平台风控。清洗规则剔除明显非助眠内容、疑似搬运及少于 3 分钟的视频；规则分数不是医学判断，也不保证每条视频都适合每位用户。女性创作者标注来自 `scripts/creator-profiles.mjs` 的已核实频道资料，未知频道不会按头像或名字猜测。视频内容与封面归原平台和权利人所有。

### 榜单口径

- B站今日热榜：`(0.35·播放 + 0.25·点赞率 + 0.20·收藏率 + 0.20·七日增速) × exp(-发布天数/180)`。
- B站本周上升：仅近 30 天，`0.70·增速 + 0.15·点赞率 + 0.15·收藏率`。
- B站长尾常听：仅超过 30 天，`0.45·收藏率 + 0.30·点赞率 + 0.25·播放`。

分项在候选集内归一化；暂无七日快照时，增速分沿用现有算法的中性值 0.5。平台热门作品只按同平台公开播放量排列，不伪造跨平台分数或排名趋势。

### 已知数据限制

- 现有数据没有每条 YouTube 视频的首次收录时间。“最近有快照”仅按视频已保存的快照时间排序；没有逐条快照的作品排在后面。页面中的数据更新时间指整份索引生成时间。
- 外部视频可能因平台限制、地区限制或下架暂时无法打开；不能仅凭访问失败认定删除。
- 搜索与内容筛选是自动规则，仍可能出现相关性误差。可在 `scripts/screening.mjs` 调整规则，随后运行测试与 `npm run sanitize`。

## 设计与验收

唱片店视觉版采用暖纸色、橄榄绿和编辑目录式排版，首页陈列新近发布作品、本周 B站作品榜与创作者入口。新近发布按视频发布时间展示；现有数据不支持准确的逐条收录时间。改版前后截图见 [docs/record-store](docs/record-store)。
