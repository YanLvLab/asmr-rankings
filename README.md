# 静响榜 · HUSH INDEX

🌐 **在线网站：[立即打开静响榜](https://yanlvlab.github.io/asmr-rankings/)**

一个可以直接部署的 YouTube 与哔哩哔哩助眠 ASMR 资源中转站，包含视频库、创作者榜和 B站独立算法榜。

## 已完成

- 无密钥抓取 YouTube 与哔哩哔哩公开数据，增量去重并保留历史合格条目
- 无需 YouTube API 密钥
- 自动读取时长、封面、播放量、点赞量、发布时间和创作者
- 双平台资源库、博主榜、B站今日热榜、本周上升、长尾常听
- 平台、时间、时长、分类、排序和关键词筛选
- “只看小姐姐”总筛选同时作用于视频榜和博主榜；频道标注随新视频自动继承
- 自动排除反应、测评、挑战、恶搞、教程、短片、擦边、食物吃播、广告和疑似搬运
- 少于 3 分钟的内容一律剔除
- B站每日保存播放/点赞/收藏快照，积累七天后自动采用真实增速
- 自适应桌面与移动端布局
- GitHub Actions 每天自动刷新并发布 GitHub Pages
- 每次采集将榜单与快照写回仓库，供下一次计算七日增速

筛选器采用高精度策略：宁愿少收录，也不让只有 ASMR 标签的无关视频进入榜单。

## 本地运行

```powershell
npm install
npm run dev
```

## GitHub 部署

1. 新建 GitHub 仓库，将本目录作为仓库根目录推送。
2. 打开 `Settings → Secrets and variables → Actions`。
3. 打开 `Settings → Pages`，Source 选择 `GitHub Actions`。
4. 在 Actions 页面手动运行一次 `Deploy frontend`。

不需要添加任何 API Key 或 Repository Secret。工作流每天约北京时间 05:17 自动采集、清洗、测试、保存快照、构建并发布。若平台接口暂时不可用，页面继续使用仓库中的上一版数据，并显示来源状态。

## 数据说明

展示数据位于 `public/data/rankings.json`。运行 `npm run collect` 更新 B站数据，运行 `npm run collect:youtube` 无密钥更新 YouTube 数据，运行 `npm run sanitize` 对整个历史库重新执行硬性排除规则。YouTube 缩略图直接使用公开视频的官方缩略图地址，点击后跳转到原视频。本站不下载或重新分发视频内容。

B站三个算法榜沿用固定权重：

- 今日热榜：35% 播放、25% 点赞率、20% 收藏率、20% 七日增速，并乘以 `exp(-发布天数/180)`；
- 本周上升：70% 七日增速、15% 点赞率、15% 收藏率，仅收录近 30 天内容；
- 长尾常听：45% 收藏率、30% 点赞率、25% 播放，仅收录发布超过 30 天内容。

没有七日前快照时，增速分按 0.5 的中性值计算；权重不因数据缺失而改变。此时页面将“本周上升”暂称为“近期新作”，直至有真实七日增速可用。

“只看小姐姐”使用 `scripts/creator-profiles.mjs` 中的预置频道 ID 和频道明确自述。平台公开数据没有统一的博主性别字段，因此未标注频道不会根据头像、昵称或单条视频标题猜测归类。运行 `npm run annotate:hosts` 可重新给现有数据写入频道分类；日常采集和清洗流程会自动执行这一步。

`screeningConfidence` 是内部规则积分，不是概率或平台官方指标，页面仅显示是否通过筛选；视频和创作者榜次按公开播放量或粉丝/订阅数排列。B 站简介直接标注 YouTube 原视频链接的条目会被视为疑似转载并剔除。
