隐私政策

静响榜是一个自动整理公开 ASMR 视频信息的静态网站。网站本身不要求登录，不建立用户画像，也不收集姓名、邮箱或其他身份信息。

数据来源

网站前端内置经过筛选的公开视频资料，并通过原平台链接和缩略图进行展示。当前版本不需要任何 API 密钥，也不下载、缓存或重新分发视频文件。

第三方服务

当你打开视频链接或第三方缩略图时，相应平台可能按照其政策处理网络请求。使用 YouTube 相关功能即表示你同意 YouTube 服务条款。请同时阅读 Google 隐私政策。

数据保存与刷新

榜单仅保存展示所需的有限公开字段和本站自己的内容分类结果。失效或被删除的视频会在后续版本中移除。

本地存储

当前版本不使用广告 Cookie，也不保存浏览历史。若以后加入统计服务，本政策将先行更新并明确说明。

联系与删除

创作者如希望更正信息或移除本站记录，可通过项目 GitHub Issues 提交请求；核实后会在七日内处理。
